# ML From Scratch

Educational implementations of Machine Learning algorithms using Python and NumPy.

## About

This repository documents my journey of learning Machine Learning by implementing algorithms from scratch.

The goal is to understand the mathematics, intuition, and implementation details behind common Machine Learning techniques rather than relying solely on existing libraries.

## Disclaimer

These implementations are intended for educational purposes and are not designed to be drop-in replacements for production libraries such as scikit-learn.

Many optimizations, edge-case checks, numerical stability improvements, and advanced features found in mature libraries may be intentionally omitted in favor of clarity and learning.

## Project Structure

```text
mlfs/            # Main library implementations
archive/         # Earlier learning implementations
examples/        # Usage examples
tests/           # Unit tests
datasets/        # Dataset storage (ignored by git)
scripts/         # Utility and dataset download scripts
```

## Installation

```bash
pip install -r requirements.txt
```

## Download Datasets

```bash
python scripts/download_datasets.py
```

## Goals

* Learn Machine Learning from first principles
* Implement algorithms from scratch
* Compare results with scikit-learn
* Practice software engineering and OOP design
* Build a reusable educational ML library
